# DVAG workshop

Install SF CLI by following instrutions [here](https://developer.salesforce.com/docs/atlas.en-us.sfdx_setup.meta/sfdx_setup/sfdx_setup_intro.htm)

## Commands

1. Login `sf org login web -s -a mydevorg -r https://test.salesforce.com`
